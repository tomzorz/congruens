# Records

Where information produced while working in this area gets recorded. Read by the `record` skill when it has something to write; created by `record-setup`. Edit by hand when the answers change.

## Area

- Scope: this repository
- Version control: git, GitHub `tomzorz/congruens`, public
- Spec language: Lojbanlite (no specs exist yet)
- Spike sandbox: `spikes/`, committed, created on the first spike

## Destinations

| Kind | Where | Notes |
|---|---|---|
| Rule | `AGENTS.md` at the repo root | Rules that apply on every machine go to the shared profile in `agents/config/AGENTS.md` instead. |
| Code fact | Comment at the site | |
| Design | README section; `docs/` once a second document exists | |
| Decision | Inline in the affected doc or rule, dated | |
| Finding | Inline in the doc it informs | A no-go with nothing to inform is not kept; the spike commit is the record. |
| Procedure | README section; `docs/` once a second document exists | |
| Diagram | `docs/diagrams/` | Created on first use. Referenced from the section it explains. |
| Parked work | GitHub issues | Drafted and shown before creation. |
| Question | Ask; `ASSUMPTION:` comment at the site when the user is away | |
| Machine fact | Not in this repo | Public repository. Machine notes live on the machine, never here, not even as examples. |
| Not recorded | Progress, status, summaries of finished work, one-off trivia, anything the code or git history already says | |
